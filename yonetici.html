Selçuk Tıp – bağlantı yönetimi

TıpNote uygulamasındaki dönem notu bağlantılarını buradan düzenleyin.

Giriş

Kaydetmek için GitHub erişim anahtarı gerekir. Anahtar yalnızca bu cihazın tarayıcısında saklanır.

Anahtar nasıl alınır? (bir kez, 2 dakika)
  1. github.com/settings/personal-access-tokens/new adresini açın.
  2. Token name: TıpNote yönetim, Expiration: 1 yıl.
  3. Repository access: Only select repositories → tipnote-privacy.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token → çıkan anahtarı kopyalayıp yukarıya yapıştırın.

Genel

Yeni öğretim yılı

Her dönemin başına yeni yıl ekler ve onu "güncel" yapar; eski yıllar geçmiş olarak kalır.

Bağlanmak için anahtarınızı girin.
