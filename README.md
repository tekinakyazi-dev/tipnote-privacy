# TıpNote – herkese açık sayfalar

- Gizlilik politikası: https://tekinakyazi-dev.github.io/tipnote-privacy/
- Selçuk Tıp bağlantı listesi (uygulama bunu okur): https://tekinakyazi-dev.github.io/tipnote-privacy/selcuk-tip.json
- **Yönetici paneli:** https://tekinakyazi-dev.github.io/tipnote-privacy/yonetici.html

## Bağlantıları güncelleme

1. Yönetici panelini açın (telefondan da olur).
2. İlk seferde GitHub erişim anahtarını girin (paneldeki "Anahtar nasıl alınır?" adımları; yalnızca bu depoya *Contents: Read and write* izni).
3. Dönemi açın → yıl satırına Drive klasör bağlantısını yapıştırın → **Kaydet ve yayınla**.
4. 1–2 dakika içinde uygulamada görünür (öğrenciler listeyi aşağı çekerek yeniler).

Yeni öğretim yılında "Yeni öğretim yılı" kutusuna `2026-2027` yazıp **Tüm dönemlere ekle** deyin; yeni yıl güncel olur, eskiler geçmiş yıllar olarak kalır.

Drive klasörlerinin paylaşım ayarı **"Bağlantıya sahip olan herkes – Görüntüleyen"** olmalı.
